# 直播间场景 Skill V3.0.0

面向全棉时代与奈丝公主的直播间背景设计。将运营需求、参考图分析、品牌规范、构图安全区、提示词、生图及多轮反馈沉淀为团队可复用工作流。

## 五分钟上手
1. **提交需求**：选择品牌、品类、坐播/站播、纯室内/半户外/纯户外、活动氛围，以及有无参考图。
2. **有参考图**：先上传本项目参考图；AI只分析与提出设计方向，**未经确认不生图**。**无参考图**：AI先提出自主设计方向，同样等待确认。
3. **确认方向后**：先输出完整可复制提示词与A/B/C差异指令，再生成三张独立背景图。
4. **选图优化**：选择A/B/C或历史版本，点选修改事项；局部修改优先锁定原图编辑，不随意重新设计。
5. **每轮结束**：必须出现选图与下一轮修改选项，不可只发图。

## 固定设计原则
- 3:4大场景背景，镜头后退，四周预留扩图/裁切空间；兼顾9:16直播画面。
- 顶部简洁用于标题，中间留主播，Logo位于左或右，底部留地面/台面贴片。
- 明媚、柔光、通透、空间纵深是经验优先级，不宣称未经核验的转化提升。
- 尽量用真实比例的少量棉花点缀。
- 全棉时代采用全棉绿 #00AC97；奈丝公主遵循其标准品牌资产。
- AI无法保证Logo绝对一致，最终须用官方原始Logo合成。
- 不假设实体搭建：多数用于幕布印刷或蓝幕合成。
