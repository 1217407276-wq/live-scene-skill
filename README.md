# 直播间场景 Skill V3.3｜轻量版

全棉时代 × 奈丝公主｜设计团队可复用的直播背景设计规范与历史场景经验库。

## 目前采用的工作方式（2026-10-23更新）
**需求确认 → 上传本项目参考图并拆解（没有图则自主提案）→ 用户确认方向 → 完整可复制提示词 + 默认3张独立3:4图片 → 用户自行将喜欢的图片发回对话，直接用口语微调 → 定稿安全区检查。**

**不再强制出图后的A/B/C选图面板、多选反馈卡或专用口令。** 用户无需记图片编号，直接在对话里贴出自己要修改的图片。需求配置与方向确认仍可以用轻量点击选项。

## 执行重点
- 尚未确认方向时不生图；有本项目参考图须先拆解。
- 每轮先完整提示词、再出图，默认3张独立图片；不足如实标注。
- 微调优先使用用户**最新实际提交的图片**作为编辑输入，不能凭文字重绘冒充原图编辑；不动未授权的布局结构。
- 顶部/底部清爽可排版、中间主播区、左右Logo在9:16裁切内避让人物和直播UI；3:4等高居中裁为9:16左右各去12.5%原图宽。
- 全棉时代标准绿 **#00AC97**；奈丝公主常用主色 **#47B7B7** 和 **#E874A9**，安睡裤偏紫。官方Logo与标准色需原素材校核，不以AI拟图为准。
- 棉花比例真实、自然光明媚、前中后空间有纵深；历史上线截图仅提炼经验，**不把评论/商品UI/人物生成进纯背景**。
