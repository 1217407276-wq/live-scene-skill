# 直播间场景 Skill V3.3｜团队验收用例（轻量版）

以下是**待在实际平台测试**的场景，不得将文档更新宣称为实机全部通过。

| 编号 | 测试情境 | 期望结果 |
|---|---|---|
| T01 | 新项目，上传本项目参考图 | 收集需求、分析参考图，方向未确认不生图 |
| T02 | 新项目无参考图 | 先给设计方向并等待用户确认 |
| T03 | 方向确认并出图 | **完整可复制提示词在先，默认3张独立3:4图在后** |
| T04 | 图像工具提前结束回复 | 不影响轻量流程，不追补A/B/C反馈面板 |
| T05 | 用户贴回刚生成的一张图说“左侧棉花减半” | 使用**这张真实图片**进行编辑，其他结构不擅自改变 |
| T06 | 用户贴回旧图，要求后退镜头 | 以本次用户实际贴回的图为准，优先编辑/扩图，不因“最新A/B/C”选错 |
| T07 | 图像编辑平台无法使用当前原图 | 诚实说明，不以纯文生图冒充原图编辑 |
| T08 | 全棉时代CNY白色Logo与#00AC97 | 校核真实官方白版和标准色；只知道路径不算载入 |
| T09 | 奈丝公主卫生巾/安睡裤 | 主色#47B7B7/#E874A9；安睡裤偏紫，不混品牌Logo |
| T10 | 3:4母版居中裁9:16 | 中心保留75%宽，左右各裁12.5%；Logo/主播/标题/贴片互不冲突 |
| T11 | 站播实际截图作为参考 | 识别真人与UI遮挡，不把评论/商品卡/右侧按钮复制入背景 |
| T12 | 家纺/家居服任务 | 床、窗帘、天然材质、明媚阳光、镜头距离和上下留白符合预期 |
| T13 | 棉花与绿植替换 | 使用现实比例棉枝，优先指定局部区域，不生巨型棉花树 |
| T14 | 红绿新春改方向 | 现代新中式、装饰克制，用户调节品牌绿面积且保留精确标准色 |
| T15 | 用户只说“继续做图” | 不强制索要A/B/C或技术ID；按当前明确需求继续设计 |
| T16 | 同事在ChatGPT/豆包安装更新 | 必须确认导入最新版规则及Logo实际素材；GitHub更新不自动同步 |

最终上线：需要在目标使用平台进行至少一轮“需求→参考图→方向确认→3图→用户直接贴回图微调→安全区”测试，并记录任何图像工具限制。
