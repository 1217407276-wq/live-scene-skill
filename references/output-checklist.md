# V3.1 每轮出图硬性自检

## 生图前
- [ ] 项目、轮次、阶段、已确认方案标识明确
- [ ] 标准需求确认卡已展示并确认
- [ ] 官方Logo实际是否可读已核实，不能把已知路径当已读取
- [ ] 全棉时代 #00AC97 / RGB(0,172,151) 已作为配色约束
- [ ] 有图分支已收本项目图片并拆解；未确认前没有生图
- [ ] 历史选图有准确原图ID及锁定卡，保留/允许改动/禁止改动清晰

## 生图当轮
- [ ] 在调用生成/编辑工具之前已给完整可复制提示词、负面提示词、A/B/C差异
- [ ] 固定三张独立3:4图片，禁止拼图；不足3张已如实报告
- [ ] 锁图修图均基于同一真实原图，不以重新生图冒充编辑
- [ ] 上下留白、空间纵深、品牌色、真实比例棉花符合要求
- [ ] 输出真实的图片数量、版本名及限制

## 出图后（不得跳过）
- [ ] 即使工具只输出图片，也继续文本/控件反馈
- [ ] A/B/C/都不满意/历史版入口齐全
- [ ] 多选修改项目、自由反馈及追加参考图入口齐全
- [ ] 不支持按钮则输出编号文字备选
- [ ] 下一轮未获新指令不得自动再生成

## 定稿
- [ ] 提供9:16安全区裁切检查；左右各预留12.5%母版宽度（居中裁切基准）
- [ ] 主播位置、标题、底贴片、Logo是否受遮挡有明确检查状态
- [ ] 官方Logo需源图后期合成；品牌色需校色，不能凭AI描述承诺绝对准确
- [ ] 输出最终提示词、版本ID、未解决风险/人工待办
