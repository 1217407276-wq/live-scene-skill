# V3.3 轻量流程与直播画面自检

## 方向确认前
- [ ] 已读取用户本次品牌、品类、直播方式、空间、节庆氛围和运营备注（不重复问已提供的内容）。
- [ ] 用户有参考图则等待本项目实际上传，拆解指定借鉴维度；未获方向确认不生图。
- [ ] 官方Logo文件实际可用状态明确；不会把GitHub路径误当作当前模型已载入。
- [ ] 标准配色、棉花真实比例、上下留白及9:16直播遮挡已纳入设计要点。

## 生图时
- [ ] **先**输出完整可复制中文提示词，必要负面词和三图微差。
- [ ] 默认3张独立3:4图片；用户指定其他数量则遵循用户；生成不足如实说明。
- [ ] 画面简约、高级、自然光明媚、空间有纵深，顶部/底部便于排版和直播贴片。
- [ ] 纯背景不带直播平台UI、商品浮层、价格、主播人物或额外品牌元素，除非用户要求。
- [ ] **不再输出A/B/C选图面板、多选反馈卡、自由输入卡**；图像工具结束后也无需补面板。

## 用户直接贴图修图
- [ ] 接收到的真实图片为本轮基准，未偷换别的历史图片。
- [ ] 明确要改什么、不改什么；优先对所附真实原图做编辑/扩图。
- [ ] 不能把纯文字重绘伪称成功锁图。
- [ ] 修图仍先提示词后出图，不加选图面板。
- [ ] 发生未经许可的建筑、窗户、家具、Logo墙大改，要明确说明。

## 定稿
- [ ] 3:4母图到9:16的实际裁切核对；等高居中时左右各损失12.5%原图宽。
- [ ] Logo在最终有效可见区，避开主播/右侧UI/顶部标题、底部商品信息。
- [ ] 官方Logo原图合成/核对、全棉绿#00AC97校色，奈丝公主遵循项目主色。
- [ ] 棉花真实比例，所有图像版本与最终场景接受人工审定。
