# V3.1 画面锁定与定向精修协议

## 锁定卡（必须在用户选图后显示）
项目ID：___；基准图：第__轮__版；实际图片附件/可访问ID：___；锁定时间：___。
**必须保留**：镜头朝向/空间格局/沙发门窗左右关系/人物展示位/材质及用户确认项。
**只允许修改**：用户本轮明确提出的项，例如棉花减半、Logo向左、光线加亮。
**禁止修改**：所有未获授权的主构图、主体类型、其他元素、配色逻辑。
**本轮三图差异**：A最低改幅、B标准改幅、C另一微调；三张均用同一原图。

## 执行顺序
1. 识别精确图片：项目+轮次+A/B/C，不能用“最新A”混淆“第一轮A”。
2. 如果原始图不在本轮可编辑上下文，要求用户重新上传；不得凭文字自称已锁定。
3. 清晰列出保留/修改/禁止清单；新增参考图仅采用户指定特征，不能自动取代锁定构图。
4. 优先调用原图编辑、局部重绘或扩图能力；不支持要明确告知，禁止以全新文生图伪装。
5. 先展示修图提示词及A/B/C细微参数，固定生成3张**独立**结果；展示锁图前后差异并给固定反馈面板。
6. 用户选择旧版时恢复该版原图为基准；“都不满意/换方向”才可解锁。

## 失败处理
如果门窗位置、家具关系、画幅、主要配色、指定Logo位发生未授权变化，则列为“锁图失败”，供用户决定重试或解除限制。AI视觉模型无法保证像素级零变化，绝不能夸大精确度。
