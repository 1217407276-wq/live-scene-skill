# V3.3 原图优先与定向精修规范（简化版）

## 从用户当前贴回的真实图片开始
最新约定：用户会直接复制/上传自己认可的图片到聊天框，并用口语说明修改。**当前提交的实际图片是唯一优先原图**；不要把其他轮次编号相似的图替换进去。普通设计师不需要管理原图ID、哈希或版本档案。

### 后台最小核对
- 是否实际收到图片像素/附件，可否直接供图像编辑工具使用；“知道路径/历史生成ID”≠“已实际传入编辑工具”。
- 本次“保留内容 / 允许修改 / 禁止改动”各是什么。**用户没提出改的布局和已确认区域默认保持。**
- 若用户要求扩大空间或镜头后退，优先使用真实原图的扩图/画布延展；不是换房间重画。不能保真应坦白。

### 正确修图执行
1. 以用户最新贴回的图片为编辑输入，先形成完整可复制修图提示词。
2. 改动限制在明确指定的局部或维度，保留床、窗、沙发、柜子、建筑透视、Logo区、光线关系等未授权元素。
3. 用户新给的参考图只继承其指定方面（如光感），不能取代目标原图。
4. 默认尝试3张同原图、同方向、小幅差异结果（如果工具允许真实编辑多张）；实际数量不能造假。
5. 出图后**不弹选图反馈卡**。用户需要再改会继续贴图和提要求。
6. AI图像编辑无法保证其他像素完全不变；审图发现大改则诚实标记“修改跑偏”，不宣称“像素级锁图成功”。

### 不可访问图片时
优先检查当前对话已经可用的上传、项目附件及工作区文件；只有确实缺少能供编辑工具使用的原图才说明具体问题。不要让用户重复上传系统已可正常访问的图，也不要假装已把真实图片传入工具。

### 解除锁图
用户明确说“重新设计/整体换构图/都不满意”时，才允许从头设计；更换方向时保留已确认的品牌规范、主题与安全区要求。
