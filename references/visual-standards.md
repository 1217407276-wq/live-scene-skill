# 直播间视觉规范｜长期复用经验 V3.3

> 知识来源：用户日常视觉设计偏好、实际设计反馈、2026-10-23历史上线直播截图观察。属于设计实践方法和选图标准，**不是经严谨A/B测试证实的转化率规律**。当次运营诉求及参考图优先；这里提供默认设计判断。

## 1. 场景目标和应用方式
- 背景通常用于直播画布、直播间绿幕抠像或后期合成，不是单纯的建筑效果图；**无需将实际建筑搭建可行性视作唯一限制**。
- 首要衡量：合规品牌识别、观看时干净不拥堵、主播适配、运营贴片可排版、手机裁切后主视觉不丢、真实高质感。
- 图片应能直接作为**无UI、无销售文字的纯净场景底图**。原直播截图中的灰色占位、评论、购物车、商品卡、主播人物是观察遮挡关系的依据，不是应生成的背景物体。

## 2. 构图和安全留白
- 默认**3:4母图，较远视角，接近24mm广角的空间感**；摄影机后退，主体比例不过大，画面保留较多天花/天空、地面及左右延展空间。24mm是视觉提示，不是必须精确参数。
- 顶部：低纹理、简约，留活动主标题/品牌贴片区。中间：给主播站位与产品。底部：地面、桌台与场景信息不过密，避开评论、商品卡、下贴片。
- 坐播：人坐在中下区，沙发/桌和产品可能被人物及UI遮挡；站播：留足站立全身比例和前方地面。
- 左/右Logo优先完整平整墙面，避开主播、右侧平台按钮和裁切边缘。Logo不固定必须左或右；参考现场构图决定。
- 3:4母图等高居中转9:16：中间保留75%母图宽，左右各切12.5%。顶部/底部预留比例**没有放之四海皆准的固定数字**，需要用户平台实际遮挡图验证。
- 视觉主体通常应分成前景（地面/轻道具）、中景（主播/床沙发/展品）、后景（建筑/窗/庭院/雪山/棉田等）。避免透视挤压、天花过低、密集元素塞满中心。

## 3. 光线与材质
- 偏好**明媚、真实、清透的自然光**，柔和且清晰的投影，商业室内摄影质感；避免大面积灰雾、曝光死白、灯带过多产生廉价感。
- 主光可从右上或场景中的窗/庭院自然落入，尊重参考图真实光位；不拘泥固定角度。
- 家居：暖白、米杏、浅原木、自然棉麻、透纱、微水泥/肌理墙。床品、家居服需有真实细纹、柔软褶皱与可感知面料品质。
- 外出/半户外：庭院、窗门/露台、远景层次，合理组织前中后空间；可以高端酒店度假感，但景观与窗洞要有明确主次。

## 4. 棉花与植物比例
- 棉枝、成熟棉桃和小花器用**现实比例**；不能出现夸张球团、巨大白色“棉花树”，更不能铺满空间挡主体。
- 优先放左右边角的瓶插/侧景/陈列桌，不压住Logo，不挡窗外雪山棉田。
- 如果用户说“把绿植替换棉花”，应保留原植物区域及场景关系做真实比例替换；用户说“去掉绿植”则不自行新增其他绿植。

## 5. 产品与主题分类
| 场景类别 | 可优先采用的设计语言 | 常见应规避项 |
|---|---|---|
| 棉柔巾、湿巾 | 洁净现代家居/自然背景、少量棉枝、精简陈列 | 伪包装文字、超大棉花、墙面太满 |
| 婴童用品 | 柔和暖白、自然材质、轻微童趣/玩具 | 幼稚碎元素、衣服过多 |
| 家居服/床品 | 床或沙发、透纱窗、原木、舒适软材质和明显日光 | 床挤满镜头、顶部无Logo位 |
| 外出服 | 明媚半户外/酒店露台/庭院、观景窗、少量挂衣架 | 背景喧宾夺主、中心站位被挡 |
| 内裤/功能专题 | 现代产品展架、淡品牌绿、专业研发陈列 | 大字报无授权、展品过大 |
| CNY/节日 | 红为主、暖金和局部标准绿，现代新中式弧线/廊院、少量灯笼与棉枝 | 过度复古、密集窗格、巨大灯笼、遍布红花/松树 |
| 大促 | 正红/暖金/品牌绿合理分工，现代层叠空间感与一两处主装置 | 巨型文字/促销UI画入背景、廉价满铺 |
| 奈丝公主安睡裤 | 紫色系和轻柔寝居/月夜线索，室内依然明亮 | 过暗、粉绿品牌混用 |

## 6. 近期CNY项目的设计纠偏经验
在全棉时代棉柔巾CNY半户外坐播任务中，用户确认：
- 保留**红色主调、少量暖金、部分全棉绿 #00AC97、白色官方Logo要求、少量棉枝**与明媚自然光。
- 相比厚重复古庭院，更偏**现代简约的新中式空间感**；红色+品牌绿面积按反馈可调整，不可把品牌绿压成几乎没有。
- 避免过多红色树枝花叶、密集栅栏与传统窗格、硕大灯笼、松杉树；以正常比例棉枝代替指定不喜欢的植物。
- 视觉焦点、光感、空间深度和上下排版留白，比“更多春节符号”更重要。
- 用户已决定：**出图只要完整提示词+图片；自己贴图进行后续修改，不要选图面板**。

## 7. 复用方式
先根据用户本次需求与参考图确定方向，再适当调取 `references/historical-cases.md` 中相近案例的**具体设计方法**（构图/光感/场景尺度/装饰），不是复制历史截图本身，也不是照搬其直播UI或人物。
