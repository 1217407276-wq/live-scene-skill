# 同事5分钟上手教程
**第一步：新需求** 选择品牌、品类、坐播/站播、空间类型、是否有参考图，并写运营补充要求。
**第二步：参考图分支** 有图：先提交需求，再在ChatGPT输入框使用“+”上传多张图片；AI只分析，不会直接生图。无图：AI自主提出一个方向。
**第三步：确认方向** 看AI拆解构图、光感、材质与改造点。点击确认才能开始生图。
**第四步：看三张图和提示词** 先看完整AI提示词，再对比A/B/C三张独立图。背景默认无人/无贴片。
**第五步：反馈修改** 选A/B/C或历史版本，点选“镜头后退/棉花减少/Logo换边/光感加强”等，也可以追加参考图指定只参考光线或构图。
**第六步：拿到结果** 继续迭代，锁定已选图片，直至设计师认可。Logo最终使用官方原图合成。

注：聊天原生图片上传使用输入框“+”，并非Skill创建自定义附件按钮；图文教学中的界面仅为交互示意。
