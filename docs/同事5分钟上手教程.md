# 直播间场景 Skill V3.3｜同事5分钟上手

## 一张图看流程
**填需求 → 发参考图 → 确认方向 → 拿到完整提示词和3张背景图 → 自己贴回要改的那张图 → 口语说修改 → 最终核对直播安全区。**

### 操作步骤
1. 打开最新版直播间场景Skill，提供品牌、品类、坐播/站播、室内/半户外/户外、日常/大促/节庆、官方Logo版式和运营要求。可以点选需求卡；如果已经写得清楚，AI不重复问。
2. 有参考图就直接通过聊天框上传，并说主要参考构图、光感还是配色。AI只分析与提出方案；**你确认后才生图**。没有参考图则先看方案提议。
3. AI应先给完整可复制的中文提示词，然后默认生成3张**分别独立**的3:4背景图。
4. **不需要点击或等待A/B/C选图卡。** 哪张满意，就把那张图直接粘贴/上传回聊天输入框，例如“以这张图为基准，只减少棉花、把镜头后退一点，其他不变”。
5. AI继续先给本轮修图提示词再编辑出图；会尽量保留未提出修改的家具、建筑、Logo墙和景观。若编辑工具不支持真实原图编辑，会明说。
6. 最终使用前核对9:16：3:4等高居中裁切左右各失去12.5%原图宽，保证主播、Logo、标题和下方商品贴片相互避让。全棉绿 `#00AC97`、奈丝公主双主色和官方Logo以真实素材校验。

### 牢记
- **纯背景**默认不要直播评论区、商品卡、主播、营销大字。
- 设计偏好：自然光明亮、空间宽敞、上下留白、真实比例棉枝。
- 如果要参考团队历史上线案例，使用 `references/historical-cases.md` 的结构与规律；不要复制历史截图中的主播/UI。
- GitHub更新后已装好的第三方Skill**可能需要重新更新/导入**；不能靠仓库更新自动触发模型记忆。
