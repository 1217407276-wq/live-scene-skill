# V3.1 同事5分钟上手教程

1. 启动直播间场景 Skill，完成需求确认卡：品牌、品类、坐播/站播、场景、活动、Logo左/右/自动、有无参考图、运营备注。
2. 检查“品牌资产状态”：全棉时代绿色/白色Logo及色卡、奈丝公主Logo必须实际读取；只有文件名不算读到。
3. 有参考图就在聊天输入框原生上传本项目图片，确认参考内容要借鉴哪里；没有图则看AI提案。**明确确认方向前不要生图**。
4. AI先给完整提示词、负面词和A/B/C微差，再生成**3张独立3:4**图片。第一轮也如此。
5. 图片出现后**一定继续看到选图面板**：A/B/C/都不满意/历史版；可多选镜头后退、Logo、光感、棉花、安全区等。若没有按钮就用编号回复。若只有图没有选项，请让AI“补发V3.1反馈面板”，并反馈为测试失败。
6. 选中版本后确认锁定卡，例如“第2轮B”；修改必须使用这张原图（必要时重新上传），下一轮**依然固定3张**，保持未授权元素不变。
7. 定稿前检查9:16裁切安全区：居中裁切左右各损失3:4母图宽度12.5%；检查主播、标题、底部贴片和左右Logo。正式Logo用官方图合成，全棉绿精确要求时后期校色。

注意：GitHub仓库更新后，豆包及其他Skill安装实例通常需要重新导入或手动更新；不能把GitHub上传当成第三方模型已记住Logo。
